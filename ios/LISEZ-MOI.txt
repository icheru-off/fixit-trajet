FixIT Trajet — application iPhone (Swift / SwiftUI, iOS 16 minimum)

Pour obtenir le fichier .ipa : envoyez le CONTENU de ce dossier (ios/ et .github/) à la racine
d'un dépôt GitHub privé, puis onglet Actions › Build IPA › Run workflow. Détails : GUIDE-INSTALLATION.html, partie 4.

Fichiers :
  project.yml                 description du projet (XcodeGen génère le projet Xcode)
  FixitTrajet/TripManager.swift   GPS natif en arrière-plan, file d'attente hors-ligne, envoi par lots
  FixitTrajet/PointQueue.swift    positions sauvegardées sur l'iPhone jusqu'à réception par le serveur
  FixitTrajet/APIClient.swift     échanges avec https://suivi.fixit-service.fr/api/app.php
  FixitTrajet/Views/              écrans : configuration, liste des interventions, trajet (carte Apple Plans)

Sur un Mac (facultatif) : brew install xcodegen && cd ios && xcodegen generate && open FixitTrajet.xcodeproj
